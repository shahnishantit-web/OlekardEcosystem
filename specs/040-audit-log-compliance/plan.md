# Implementation Plan: ADM-P1-016 — Audit Log & Compliance

**Branch**: `040-audit-log-compliance` | **Date**: 2026-10-14 | **Spec**: [spec.md](./spec.md)

## Summary

Enhances three existing admin audit/compliance pages (`audit-events.tsx`, `compliance-status.tsx`, `retention-policies.tsx`) to fully implement ADM-P1-016: add missing filters and RBAC gates to the audit log; replace the per-user compliance status page with a proper dashboard (checklist, open items, retention deadlines with urgency colour-coding); add a confirmation dialog and hold-period guard to the retention policies editor. Adds typed audit, compliance-dashboard, and retention-policy methods to `AdminAppClient`.

## Technical Context

**Language/Version**: TypeScript 5.x / Next.js 14 App Router

**Primary Dependencies**: React 18, `@testing-library/react`, `jest`, existing `AdminAppClient`, `useAuth` (provides `hasPermission`)

**Target Platform**: Admin web app (`apps/admin/`)

**Project Type**: Next.js web application (admin portal)

**Performance Goals**: Audit log initial load ≤ 2s; compliance dashboard initial load ≤ 2s

**Constraints**: No edit/delete controls on audit events (constitution Principle 5 — immutable audit trail); retention policy changes must show confirmation dialog; RBAC gates required on all three pages

**Scale/Scope**: 3 pages enhanced; 1 client file updated; 1 test file created
