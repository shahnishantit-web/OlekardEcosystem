# API Contracts — E32 Agent Application

All requests include:
- `Authorization: Bearer <access_token>`
- `X-Correlation-Id: <uuid-v4>` (added by `CorrelationIdInterceptor`)
- `Content-Type: application/json` (POST/PATCH)

Financial mutation requests additionally include:
- `Idempotency-Key: <uuid-v4>` (generated by app before submission)

Error envelope (all endpoints):
```json
{
  "message": "Human-readable error",
  "errors": { "field": ["Validation message"] },
  "code": "machine_readable_code"
}
```

## Authentication

### POST /v1/agent/auth/login

**Request**:
```json
{
  "phone": "+26771234567",
  "pin_hash": "$2b$10$..."
}
```

**Response 200**:
```json
{
  "access_token": "eyJ...",
  "refresh_token": "eyJ...",
  "expires_at": "2026-10-06T10:00:00Z",
  "agent": {
    "id": "01931234-0000-7000-8000-000000000001",
    "phone": "+26771234567",
    "first_name": "Sipho",
    "last_name": "Dlamini",
    "full_name": "Sipho Dlamini",
    "location_code": "GAB-001",
    "status": "active",
    "kyc_status": "verified",
    "created_at": "2026-01-01T00:00:00Z"
  }
}
```

**Response 401**: Invalid credentials
```json
{ "message": "Invalid phone or PIN.", "code": "invalid_credentials" }
```

**Response 423**: Account locked
```json
{ "message": "Account locked. Try again in 15 minutes.", "code": "account_locked", "unlock_at": "2026-10-05T10:15:00Z" }
```

## Cash-In

### GET /v1/agent/customers?q={phone_or_wallet}

Searches by phone number or wallet number.

**Response 200**:
```json
{
  "wallet_id": "01931234-0000-7000-8000-000000000010",
  "customer_name": "Naledi Khumalo",
  "masked_wallet_number": "****-5678",
  "account_status": "active"
}
```

**Response 404**: Customer not found
```json
{ "message": "No active customer found with that phone or wallet number.", "code": "customer_not_found" }
```

---

### POST /v1/agent/cash-in

**Headers**: `Idempotency-Key: <uuid-v4>`

**Request**:
```json
{
  "wallet_id": "01931234-0000-7000-8000-000000000010",
  "amount_minor_units": 50000,
  "currency_code": "BWP",
  "pin_hash": "$2b$10$..."
}
```

**Response 200**:
```json
{
  "reference_number": "CI-20261005-0042",
  "amount_minor_units": 50000,
  "fee_minor_units": 250,
  "currency_code": "BWP",
  "customer_name": "Naledi Khumalo",
  "agent_name": "Sipho Dlamini",
  "agent_location_code": "GAB-001",
  "timestamp": "2026-10-05T09:00:00Z",
  "status": "completed"
}
```

**Response 409**: Idempotent replay — returns original 200 response

**Response 422**: Validation error (e.g., insufficient float, suspended wallet)

**Response 403** + `code: step_up_required`: Amount exceeds threshold; client must POST `/v1/agent/auth/step-up` first, then re-submit with `X-Step-Up-Token` header

## Cash-Out

### GET /v1/agent/cash-out/lookup?code={code}

**Response 200**:
```json
{
  "code": "CASH-OUT-ABC123",
  "customer_name": "Thabo Mokoena",
  "masked_wallet_number": "****-9012",
  "amount_minor_units": 20000,
  "fee_minor_units": 100,
  "currency_code": "BWP",
  "expires_at": "2026-10-05T09:30:00Z"
}
```

**Response 404**: Code not found or expired
```json
{ "message": "Pickup code not found or has expired.", "code": "code_not_found" }
```

**Response 410**: Code already redeemed
```json
{ "message": "This pickup code has already been redeemed.", "code": "code_redeemed" }
```

---

### POST /v1/agent/cash-out

**Headers**: `Idempotency-Key: <uuid-v4>`

```json
{
  "code": "CASH-OUT-ABC123",
  "pin_hash": "$2b$10$..."
}
```

**Response 200**:
```json
{
  "reference_number": "CO-20261005-0018",
  "amount_minor_units": 20000,
  "fee_minor_units": 100,
  "currency_code": "BWP",
  "customer_name": "Thabo Mokoena",
  "agent_name": "Sipho Dlamini",
  "agent_location_code": "GAB-001",
  "timestamp": "2026-10-05T09:05:00Z",
  "status": "completed"
}
```

**Response 409**: Idempotent replay

**Response 410**: Code already redeemed (race condition — another agent redeemed simultaneously)

**Response 403** + `code: step_up_required`: Amount exceeds threshold

### POST /v1/agent/float/requests

**Request**:
```json
{
  "requested_amount_minor_units": 2000000,
  "currency_code": "BWP",
  "note": "Running low on float for end of month",
  "is_followup": false
}
```

**Response 201**:
```json
{
  "id": "01931234-0000-7000-8000-000000000030",
  "requested_amount_minor_units": 2000000,
  "currency_code": "BWP",
  "status": "pending",
  "note": "Running low on float for end of month",
  "submitted_at": "2026-10-05T09:15:00Z",
  "resolved_at": null
}
```

**Response 422**: Prior pending request exists and `is_followup: false`
```json
{ "message": "A float request is already pending.", "code": "pending_request_exists" }
```

---

### GET /v1/agent/float/requests/pending

**Response 200**: `FloatTopUpRequest` or `null` if no pending request
