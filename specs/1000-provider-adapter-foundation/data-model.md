# Data Model: Provider Adapter Foundation (E1000)

**Date**: 2026-08-26

---

## Overview

E1000 introduces one new database table (`platform.provider_external_references`) and a family of PHP value objects / entities that are shared across all downstream epics. No existing Platform Foundation tables are modified.

---

## Database Table

### `platform.provider_external_references`

**Purpose**: Immutable, append-only record linking each platform entity to its provider-assigned external reference. Carries the reconciliation state lifecycle. One row per outbound provider call per platform entity per operation type.

**Schema**: `platform` (existing — same as all Platform Foundation tables)

**Migration**: `2026_09_01_001000_create_provider_external_references.php`

| Column | Type | Nullable | Notes |
|---|---|---|---|
| `id` | UUID (v7) | NOT NULL | Primary key; generated by platform |
| `platform_entity_id` | UUID (v7) | NOT NULL | The OleKard entity being tracked (e.g., transaction ID, KYC verification ID) |
| `platform_entity_type` | VARCHAR(100) | NOT NULL | Discriminator string (e.g., `transaction`, `kyc_verification`, `otp_challenge`) |
| `provider_key` | VARCHAR(100) | NOT NULL | Config key name identifying the provider (e.g., `mno_primary`, `kyc_vendor`); NEVER a credential or brand name |
| `provider_reference` | VARCHAR(500) | **NULLABLE** | Provider-assigned reference ID; NULL when record is created speculatively; written exactly once when provider responds |
| `reference_confirmed_at` | TIMESTAMPTZ | **NULLABLE** | UTC timestamp of when `provider_reference` was first written; NULL while speculative |
| `operation_type` | VARCHAR(100) | NOT NULL | Normalized operation name (e.g., `initiate_payment`, `deliver_otp`, `verify_identity`) |
| `reconciliation_state` | VARCHAR(20) | NOT NULL | Enum: PENDING / MATCHED / UNMATCHED / EXCEPTION — default PENDING |
| `reconciliation_reason` | TEXT | NULLABLE | Required when `reconciliation_state = EXCEPTION`; human-readable explanation |
| `reconciliation_owner` | VARCHAR(255) | NULLABLE | Required when `reconciliation_state = EXCEPTION`; identifier of the person/process handling the exception |
| `reconciled_at` | TIMESTAMPTZ | NULLABLE | UTC timestamp when reconciliation state reached MATCHED or EXCEPTION |
| `created_at` | TIMESTAMPTZ | NOT NULL | Immutable; set at record creation; `useCurrent()` |

**Constraints and Indexes**:

```sql
PRIMARY KEY (id)

-- Provider reference uniqueness: excludes NULLs by PostgreSQL default
UNIQUE (provider_key, provider_reference)

-- Speculative record idempotency: prevents duplicate PENDING records for the same
-- logical operation. createSpeculative() returns the existing record on conflict.
UNIQUE (platform_entity_id, platform_entity_type, provider_key, operation_type)
    WHERE reconciliation_state = 'PENDING'

-- Platform entity lookup (E20 reconciliation)
INDEX (platform_entity_id, platform_entity_type)

-- Provider key + reference lookup
INDEX (provider_key, provider_reference)

-- Pending record timeout detection
INDEX (reconciliation_state, created_at) WHERE reconciliation_state = 'PENDING'

-- Exception review queue
INDEX (reconciliation_state) WHERE reconciliation_state = 'EXCEPTION'
```

**Immutability rules**:
- `platform_entity_id`, `platform_entity_type`, `provider_key`, `operation_type`, `created_at`: immutable after creation (enforced at service layer).
- `provider_reference`, `reference_confirmed_at`: one-time write — NULL → value permitted once; subsequent writes throw `ImmutableReferenceViolationException`.

**Reconciliation state transitions (E1000-managed)**:

```
PENDING   ──→  MATCHED    via match()     (provider outcome confirmed, all fields reconciled)
          ──→  EXCEPTION  via exception() (manual review; reason + owner + timestamp required)
EXCEPTION ──→  MATCHED    via match()     (exception resolved; reason + owner must be set already)
```

Rules:
- MATCHED is terminal within E1000 — no E1000 contract method transitions out of MATCHED.
- MATCHED→EXCEPTION is PROHIBITED within E1000 (throws \DomainException).
- No EXCEPTION record may transition to MATCHED without `reconciliation_reason`, `reconciliation_owner`, and `reconciled_at` all being non-null.

**UNMATCHED state (deferred)**:
The `UNMATCHED` case exists in the `ReconciliationState` enum as a reserved value. No E1000 contract method transitions a record to UNMATCHED. The PENDING→UNMATCHED and UNMATCHED→EXCEPTION transitions, and all business rules that govern them (provider settlement mismatch detection), are deferred to the epic that owns provider-specific settlement reconciliation (planned: E20). Downstream epics MUST NOT write UNMATCHED state until E20 defines the semantics.

## Domain Entity

### `ExternalReferenceMapping`

PHP readonly class (domain entity — not an Eloquent model). Constructed from database row by `ExternalReferenceMappingService`. Used by domain services for reference lookup and reconciliation state queries.

```
ExternalReferenceMapping {
    +id: string (UUID v7)
    +platformEntityId: string (UUID v7)
    +platformEntityType: string
    +providerKey: string
    +providerReference: string|null
    +referenceConfirmedAt: DateTimeImmutable|null
    +operationType: string
    +reconciliationState: ReconciliationState
    +reconciliationReason: string|null
    +reconciliationOwner: string|null
    +reconciledAt: DateTimeImmutable|null
    +createdAt: DateTimeImmutable
}
```

## Value Objects

### `ProviderRequest`

Outbound normalized request to an external provider. Immutable (readonly). No provider-specific fields.

```
ProviderRequest {
    +platformEntityId: string (UUID v7)
    +platformEntityType: string
    +operationType: string (maps to ProviderCapabilityEnum value)
    +correlationId: string (UUID v7 — propagated from calling domain service)
    +amount: Money|null     (non-null for financial operations)
    +currency: Currency|null (non-null for financial operations)
    +metadata: array        (provider-neutral key-value pairs; must not contain credentials)
}
Named constructors:
    ::forFinancialOperation(Money, Currency, string $entityId, string $entityType, string $opType, string $correlationId, array $metadata = [])
    ::forNonFinancialOperation(string $entityId, string $entityType, string $opType, string $correlationId, array $metadata = [])
```

**Invariants enforced at construction**:
- Financial constructor: `amount` must be non-null and non-zero.
- `correlationId`: must be non-empty string.
- `metadata` keys: must not include any of the reserved credential-bearing names (e.g., `api_key`, `secret`, `password`, `token`) — enforced by a blocklist check.

### `ProviderResponse`

Inbound normalized response from an external provider. Immutable (readonly).

```
ProviderResponse {
    +status: ProviderStatus (enum: SUCCESS | FAILURE)
    +providerReference: string|null  (null when provider omits reference — surrogate used)
    +amount: Money|null
    +currency: Currency|null
    +providerTimestamp: DateTimeImmutable|null
    +error: ProviderError|null       (null on SUCCESS)
    +rawProviderStatusCode: string   (preserved for audit; never used in domain logic)
    +correlationId: string
}
Named constructors:
    ::success(string $providerRef, string $rawCode, string $correlationId, Money|null, Currency|null, DateTimeImmutable|null)
    ::failure(ProviderError $error, string $rawCode, string $correlationId)
```

### `ProviderError`

Normalized provider error. Immutable (readonly).

```
ProviderError {
    +normalizedCode: ProviderErrorCode (enum)
    +providerSpecificCode: string      (raw provider error code — for audit/log only)
    +isTransient: bool                 (true = eligible for failover; false = permanent)
    +message: string                   (safe, PII-free message for audit; NOT the raw provider message)
}
```

### `ProviderCapabilitySet`

Set of declared capabilities for a provider adapter. Immutable (readonly).

```
ProviderCapabilitySet {
    -capabilities: ProviderCapabilityEnum[]  (deduplicated)
    +has(ProviderCapabilityEnum $cap): bool
    +all(): ProviderCapabilityEnum[]
    +isEmpty(): bool
    +count(): int
}
Named constructor:
    ::of(ProviderCapabilityEnum ...$caps): self
    ::empty(): self
```

### `ProviderHealthStatus`

Current health report for a bound provider adapter. Immutable (readonly).

```
ProviderHealthStatus {
    +status: ProviderStatus (enum: UP | DEGRADED | DOWN | UNKNOWN)
    +lastCheckedAt: DateTimeImmutable  (UTC)
    +reason: string|null               (optional human-readable reason for non-UP status)
}
Named constructors:
    ::up(DateTimeImmutable $checkedAt): self
    ::degraded(string $reason, DateTimeImmutable $checkedAt): self
    ::down(string $reason, DateTimeImmutable $checkedAt): self
    ::unknown(): self
```

### `NormalizedWebhookEvent`

Provider-neutral inbound webhook event produced by `ProviderWebhookContract::parse()`. Immutable (readonly).

```
NormalizedWebhookEvent {
    +platformEntityId: string|null       (null if ExternalReferenceMapping not yet created — deferred resolution)
    +platformEntityType: string|null
    +providerKey: string
    +providerReference: string
    +normalizedEventType: string         (platform-defined enum value, not provider-specific string)
    +status: ProviderStatus
    +amount: Money|null
    +currency: Currency|null
    +providerTimestamp: DateTimeImmutable|null
    +correlationId: string
    +idempotencyKey: string              (provider notification ID, or deterministic hash of rawPayload+providerKey)
    +rawPayload: string                  (preserved for audit and replay; must not be processed by domain logic)
    +receivedAt: DateTimeImmutable       (UTC — set by the caller, e.g., E25 controller)
}
```

## Exceptions

| Exception Class | Extends | Thrown When |
|---|---|---|
| `ProviderException` | `\RuntimeException` | Adapter receives an unrecoverable error it cannot normalize |
| `WebhookSignatureException` | `ProviderException` | `ProviderWebhookContract::parse()` — signature missing or invalid |
| `ImmutableReferenceViolationException` | `\DomainException` | Attempt to write `provider_reference` after it is already set |

## Entity Relationships

```
platform.provider_external_references  (E1000)
    ├── referenced by: platform.audit_events (via correlationId field)
    ├── referenced by: platform.outbox_events (via metadata.providerReference)
    └── queried by: E20 Reconciliation (by provider_key + provider_reference)

NormalizedWebhookEvent
    └── resolves platform_entity_id via: ExternalReferenceMappingService.findByProviderReference()
    └── enqueued to: platform.outbox_events (E999 outbox infrastructure)
```

## Not in Scope

The following data concerns are explicitly out of scope for E1000:

- Provider-specific tables (no `orange_money_transactions`, `kyc_submissions`, etc.)
- Retention / archival schedule for `platform.provider_external_references` (E20 concern)
- Schema migration to a dedicated `integration` schema (TBD-E1000-009 — ADR-008 addendum)
- Any audit table changes (existing `platform.audit_events` is unchanged)
