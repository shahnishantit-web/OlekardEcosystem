# API Contract — Admin Roles & Permissions

**Feature**: E04 — Roles, Permissions & Authorization
**Base path**: `/v1/admin`
**Auth**: `identity.auth` middleware required on all endpoints. Actor must be `ADMIN`.

---

## Common Headers

| Header | Required | Description |
|--------|----------|-------------|
| `Authorization` | Yes | `Bearer {access_token}` |
| `X-Correlation-ID` | No | UUID; generated by server if absent |

## Common Error Responses

```json
{
  "success": false,
  "error": {
    "code": "AUTHORIZATION_001",
    "message": "Insufficient permissions.",
    "trace_id": "uuid"
  }
}
```

| Code | HTTP | Condition |
|------|------|-----------|
| `AUTHORIZATION_001` | 403 | Actor lacks the required permission |
| `AUTHORIZATION_002` | 403 | Actor type not permitted |
| `ROLE_NOT_FOUND` | 404 | Referenced role does not exist or is soft-deleted |
| `PERMISSION_NOT_FOUND` | 404 | Referenced permission does not exist |
| `PERMISSION_ALREADY_ON_ROLE` | 409 | Permission already assigned to role |
| `PERMISSION_NOT_ON_ROLE` | 404 | Permission is not assigned to this role |
| `ROLE_SLUG_CONFLICT` | 409 | Slug matches an existing (active or soft-deleted) role |
| `SYSTEM_ROLE_DELETION_DENIED` | 422 | Cannot delete a system-seeded role |

## `GET /v1/admin/roles`

List all active roles with their assigned permissions.

**Required permission**: `admin.role.read`

**Query parameters**:

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `page` | int | 1 | Page number |
| `per_page` | int | 20 | Items per page (max 100) |

**Response 200**:

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid-v7",
      "slug": "admin",
      "display_name": "Administrator",
      "description": null,
      "is_system_role": true,
      "permissions": ["admin.user.create", "admin.role.read", "..."],
      "created_at": "2026-09-09T00:00:00Z"
    }
  ],
  "meta": {
    "total": 3,
    "page": 1,
    "per_page": 20,
    "last_page": 1
  }
}
```

---

## `GET /v1/admin/roles/{id}`

Retrieve a single role with its permission assignments.

**Required permission**: `admin.role.read`

**Path parameters**: `id` — UUID of the role

**Response 200**:

```json
{
  "success": true,
  "data": {
    "id": "uuid-v7",
    "slug": "admin",
    "display_name": "Administrator",
    "description": null,
    "is_system_role": true,
    "permissions": [
      { "id": "uuid", "slug": "admin.user.create", "display_name": "Create Admin User" }
    ],
    "created_at": "2026-09-09T00:00:00Z",
    "updated_at": "2026-09-09T00:00:00Z"
  }
}
```

**Response 404**: `ROLE_NOT_FOUND`

---

## `POST /v1/admin/roles`

Create a new role.

**Required permission**: `admin.role.create`

**Request body**:

```json
{
  "slug": "compliance-officer",
  "display_name": "Compliance Officer",
  "description": "Optional description"
}
```

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| `slug` | string | Yes | Unique, lowercase, URL-safe, max 50 chars |
| `display_name` | string | Yes | Max 100 chars |
| `description` | string | No | Max 500 chars |

**Response 201**:

```json
{
  "success": true,
  "data": {
    "id": "uuid-v7",
    "slug": "compliance-officer",
    "display_name": "Compliance Officer",
    "is_system_role": false,
    "permissions": [],
    "created_at": "2026-09-09T00:00:00Z"
  }
}
```

**Response 409**: `ROLE_SLUG_CONFLICT`

## `GET /v1/admin/permissions`

List all seeded permissions.

**Required permission**: `admin.permission.read`

**Query parameters**: `page`, `per_page`, `module` (optional filter by module)

**Response 200**:

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid-v7",
      "slug": "admin.user.create",
      "display_name": "Create Admin User",
      "module": "identity",
      "is_system_permission": true
    }
  ],
  "meta": { "total": 15, "page": 1, "per_page": 20, "last_page": 1 }
}
```

## `POST /v1/admin/roles/{roleId}/permissions`

Assign a permission to a role.

**Required permission**: `admin.role.manage`

**Request body**:

```json
{ "permission_id": "uuid-of-permission" }
```

**Response 200**:

```json
{
  "success": true,
  "data": {
    "role_id": "uuid",
    "permission_id": "uuid",
    "permission_slug": "admin.user.create",
    "assigned_at": "2026-09-09T00:00:00Z"
  }
}
```

**Errors**: `ROLE_NOT_FOUND` (404), `PERMISSION_NOT_FOUND` (404), `PERMISSION_ALREADY_ON_ROLE` (409)

---

## `DELETE /v1/admin/roles/{roleId}/permissions/{permissionId}`

Remove a permission from a role.

**Required permission**: `admin.role.manage`

**Response 200**:

```json
{ "success": true }
```

**Errors**: `ROLE_NOT_FOUND` (404), `PERMISSION_NOT_ON_ROLE` (404)

---

## `GET /v1/admin/users/{userId}/roles`

List all role assignments for a user (default role + additional roles).

**Required permission**: `admin.user.read`

**Response 200**:

```json
{
  "success": true,
  "data": {
    "default_role": {
      "id": "uuid",
      "slug": "admin",
      "display_name": "Administrator"
    },
    "additional_roles": []
  }
}
```

**Errors**: `ADMIN_USER_NOT_FOUND` (404)

---

## `POST /v1/admin/users/{userId}/roles`

Assign an additional role to a user.

**Required permission**: `admin.role.assign`

**Request body**:

```json
{ "role_id": "uuid-of-role" }
```

**Response 200**:

```json
{ "success": true, "data": { "user_id": "uuid", "role_id": "uuid", "role_slug": "compliance-officer" } }
```

**Errors**: `ADMIN_USER_NOT_FOUND` (404), `ROLE_NOT_FOUND` (404), `ROLE_ALREADY_ASSIGNED` (409)

---

## `DELETE /v1/admin/users/{userId}/roles/{roleId}`

Remove an additional role assignment from a user.

**Required permission**: `admin.role.assign`

**Response 200**: `{ "success": true }`

**Errors**: `ADMIN_USER_NOT_FOUND` (404), `ROLE_NOT_FOUND` (404), `PERMISSION_NOT_ON_ROLE` (404 — role not assigned to user)
