# API Contract — KYC Intake (Customer / Agent)

**Feature**: E05 — KYC & Identity Verification
**Base path**: `/v1/kyc`
**Auth**: `identity.auth` middleware required on all endpoints.

---

## Common Headers

| Header | Required | Description |
|--------|----------|-------------|
| `Authorization` | Yes | `Bearer {access_token}` |
| `X-Correlation-ID` | No | UUID; generated by server if absent |

## Common Error Responses

```json
{
  "success": false,
  "error": {
    "code": "KYC_CASE_NOT_FOUND",
    "message": "No KYC case found.",
    "trace_id": "uuid"
  }
}
```

| Code | HTTP | Condition |
|------|------|-----------|
| `KYC_CASE_ALREADY_OPEN` | 409 | Actor has an existing open KYC case |
| `KYC_ALREADY_APPROVED` | 409 | Actor's KYC is already in `approved` status |
| `KYC_CASE_NOT_FOUND` | 404 | Case does not exist or does not belong to actor |
| `CASE_NOT_EDITABLE` | 422 | Case status does not permit the requested mutation |
| `INVALID_CASE_STATUS` | 422 | Requested transition is not valid from current status |
| `CASE_INCOMPLETE` | 422 | Required documents or personal info missing at submission |
| `DUPLICATE_IDENTITY_DETECTED` | 409 | National ID hash matches an existing approved case |
| `INVALID_DOCUMENT_FORMAT` | 400 | Document MIME type not in `kyc.accepted_mime_types` |
| `DOCUMENT_TOO_LARGE` | 400 | Document exceeds `kyc.max_document_size_bytes` |
| `DOCUMENT_EXPIRED` | 422 | Document `expires_on` date is in the past |

## `POST /v1/kyc/cases`

Initiate a new KYC case for the authenticated actor.

**Required permission**: `kyc.case.create`
**Idempotency**: `Idempotency-Key` header supported

**Request body**: none (actor identity resolved from JWT)

**Responses**:

`201 Created` — case created:
```json
{
  "success": true,
  "data": {
    "case_id": "01966b4c-...",
    "status": "initiated",
    "attempt_number": 1,
    "created_at": "2026-09-17T10:00:00Z"
  }
}
```

`409 Conflict` — already open or already approved.

## `PUT /v1/kyc/cases/{id}/personal-information`

Capture personal details for an open KYC case.

**Required permission**: `kyc.case.update`

**Request body** (`application/json`):

```json
{
  "full_legal_name": "Jane Doe",
  "date_of_birth": "1990-03-15",
  "nationality": "BW",
  "national_id_type": "national_id",
  "national_id_number": "1234567890123",
  "address": {
    "line_1": "123 Main Street",
    "line_2": null,
    "city": "Gaborone",
    "state_province": "South East",
    "postal_code": "0001",
    "country_code": "BW"
  }
}
```

**Field rules**:

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| `full_legal_name` | string | Yes | 1–255 chars |
| `date_of_birth` | date (ISO 8601) | Yes | Must be in the past; actor must be ≥ 18 years old |
| `nationality` | string | Yes | ISO 3166-1 alpha-2 |
| `national_id_type` | enum | Yes | `national_id` / `passport` / `drivers_licence` |
| `national_id_number` | string | Yes | 1–50 chars; hashed before storage — never persisted as-is |
| `address.line_1` | string | Yes | 1–255 chars |
| `address.line_2` | string | No | Max 255 chars |
| `address.city` | string | Yes | 1–100 chars |
| `address.state_province` | string | No | Max 100 chars |
| `address.postal_code` | string | Yes | 1–20 chars |
| `address.country_code` | string | Yes | ISO 3166-1 alpha-2 |

**Responses**:

`200 OK` — personal info captured:
```json
{
  "success": true,
  "data": {
    "case_id": "01966b4c-...",
    "status": "initiated",
    "personal_information_provided": true
  }
}
```

`409 Conflict` — `DUPLICATE_IDENTITY_DETECTED` (no details about the blocking user).

`422 Unprocessable` — `CASE_NOT_EDITABLE` (status is `under_review` or later).

## `POST /v1/kyc/cases/{id}/documents`

Upload a document for an open KYC case.

**Required permission**: `kyc.case.update`
**Content-Type**: `multipart/form-data`

**Form fields**:

| Field | Type | Required | Values |
|-------|------|----------|--------|
| `document_type` | string | Yes | `national_id` / `passport` / `drivers_licence` / `utility_bill` / `selfie` |
| `file` | file | Yes | Validated against `kyc.accepted_mime_types` and `kyc.max_document_size_bytes` |
| `expires_on` | date (ISO 8601) | No | Must be in the future if provided |

**Responses**:

`201 Created` — document uploaded and validated:
```json
{
  "success": true,
  "data": {
    "document_id": "01966b4d-...",
    "document_type": "national_id",
    "validation_status": "valid",
    "file_size_bytes": 204800
  }
}
```

`400 Bad Request` — `INVALID_DOCUMENT_FORMAT` or `DOCUMENT_TOO_LARGE`.

`422 Unprocessable` — `DOCUMENT_EXPIRED` or `CASE_NOT_EDITABLE`.

## `POST /v1/kyc/documents/validate-format`

Stateless pre-check for document format. Does NOT create any records.

**Required permission**: `kyc.case.update`
**Content-Type**: `multipart/form-data`

**Form fields**:

| Field | Required | Description |
|-------|----------|-------------|
| `file` | Yes | File to validate |

**Responses**:

`200 OK` — always, with validation result:
```json
{ "valid": true }
```
```json
{ "valid": false, "error": "INVALID_DOCUMENT_FORMAT" }
```
```json
{ "valid": false, "error": "DOCUMENT_TOO_LARGE" }
```

## `POST /v1/kyc/documents/validate-expiry`

Stateless pre-check for document expiry. Does NOT create any records.

**Required permission**: `kyc.case.update`

**Request body** (`application/json`):

```json
{ "expires_on": "2025-01-01" }
```

**Responses**:

`200 OK` — always, with validation result:
```json
{ "valid": true }
```
```json
{ "valid": false, "error": "DOCUMENT_EXPIRED" }
```

## `POST /v1/kyc/cases/{id}/submit`

Submit a complete KYC case for verification. Idempotent.

**Required permission**: `kyc.case.update`
**Idempotency**: `Idempotency-Key` header supported

**Request body**: none

**Pre-conditions checked**:
1. Personal information record exists on the case
2. At least one active identity document (`national_id`, `passport`, or `drivers_licence`) with `validation_status = valid`

**Responses**:

`200 OK` — submitted (or already submitted — idempotent no-op):
```json
{
  "success": true,
  "data": {
    "case_id": "01966b4c-...",
    "status": "under_review",
    "submitted_at": "2026-09-17T10:05:00Z"
  }
}
```

`422 Unprocessable` — `CASE_INCOMPLETE` with list of missing items:
```json
{
  "success": false,
  "error": {
    "code": "CASE_INCOMPLETE",
    "message": "Required items missing.",
    "missing": ["personal_information", "identity_document"]
  }
}
```

## `GET /v1/kyc/cases/my`

Retrieve the authenticated actor's own KYC case status.

**Required permission**: `kyc.case.read`

**Query parameters**:

| Param | Required | Description |
|-------|----------|-------------|
| `user_id` | No | Admin/Compliance Officer only: look up another user's case |

**Responses**:

`200 OK`:
```json
{
  "success": true,
  "data": {
    "case_id": "01966b4c-...",
    "status": "rejected",
    "attempt_number": 1,
    "rejection_reason": "Document image is blurry. Please resubmit a clearer photograph.",
    "info_request_note": null,
    "submitted_at": "2026-09-17T10:05:00Z",
    "verified_at": null,
    "expires_at": null
  }
}
```

`404 Not Found` — actor has no KYC case.

---

## `POST /v1/kyc/cases/{id}/resubmit`

Resubmit a rejected or needs-info case. Idempotent.

**Required permission**: `kyc.case.update`
**Idempotency**: `Idempotency-Key` header supported

**Request body**: none

**Responses**:

`200 OK`:
```json
{
  "success": true,
  "data": {
    "case_id": "01966b4c-...",
    "status": "initiated",
    "attempt_number": 2
  }
}
```

`422 Unprocessable` — `INVALID_CASE_STATUS` (not in `rejected` or `needs_info`).
