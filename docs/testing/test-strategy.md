# Test Strategy

Use layered validation:
- Unit
- Integration
- API contract
- System/E2E
- Regression
- Smoke
- UAT
- Accessibility
- Performance
- Load
- Stress
- Scalability
- Resilience
- Security
- Penetration
- Disaster Recovery
- Business Continuity
- Mobile
- Cross-platform
- Cloud infrastructure

Every feature spec must define story-specific QA scenarios and release evidence.
